# Bloom branding update

This package includes the new Bloom logo/icon across the web app and adds the
assets needed for a phone home-screen installation.

The functional Mum/Partner/Baby permissions from the previous package are
preserved.

## Important Firebase note

No Firebase configuration changes are required for this branding update.
If you already published the latest Firestore rules, leave them as they are.

## GitHub Pages

Replace the repository files with this package and push/commit the changes.
GitHub Pages will serve the manifest and image assets from the same relative
paths, so the package works at `/Bloom/` as well as other relative deployment
paths.
