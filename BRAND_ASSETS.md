# Bloom brand assets

Included assets:
- `assets/bloom-logo.png` — desktop/web wordmark and tagline.
- `assets/bloom-icon-512.png` — master app icon.
- `assets/bloom-icon-192.png` — Android/PWA icon.
- `assets/bloom-icon-180.png` — iPhone/iPad Apple touch icon.
- `assets/bloom-icon-32.png` — browser favicon.
- `assets/bloom-favicon.svg` — scalable favicon wrapper.
- `manifest.webmanifest` — installable PWA metadata.

The app now references the Bloom icon for browser/app branding and includes
the PWA manifest and Apple touch icon metadata.

## Installing on a phone

### iPhone
Open Bloom in Safari → Share → Add to Home Screen.

### Android
Open Bloom in Chrome → menu → Add to Home screen / Install app.

The browser uses the supplied manifest and icon assets for the installed
home-screen experience.
