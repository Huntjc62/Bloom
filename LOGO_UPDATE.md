# Bloom logo integration

This version uses the supplied Bloom logo image throughout the site.

## Where it is used
- Login / registration screen: full Bloom logo.
- Desktop app header: full Bloom logo.
- Mobile app header: responsive full Bloom logo.
- Browser favicon: Bloom icon.
- iPhone home-screen icon: Bloom icon.
- Android/PWA home-screen icon: Bloom icon.

## Important
The previous `B` square brand mark has been removed from the login and app
header. The site now loads `assets/bloom-logo-full.png`.

After replacing the GitHub files, do a hard refresh:
- Windows: Ctrl + Shift + R
- iPhone Safari: close/reopen the tab or clear the cached site data if needed.

For an installed phone app, remove the old Bloom home-screen icon and add
Bloom to the home screen again so the phone refreshes its cached icon.
